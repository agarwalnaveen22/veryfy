# Veryfy

A mobile identity verification application built with **React Native** that uses 
facial recognition to verify guest authenticity at large-scale conferences and events.

## Features
- Facial scan and recognition for guest identity verification
- Real-time authenticity checks against registered attendee data
- Conference guest management and check-in workflow
- Secure and fast verification flow on Android & iOS

## Tech Stack
React Native · JavaScript · Facial Recognition · Jest · Android · iOS

## Testing
Unit tests configured with Jest and React Testing Library for core verification flows.
